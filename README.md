# Pedidos Tru Back - Proyecto de Desarrollo Backend

Este repositorio contiene el código y recursos para el desarrollo backen de nuestra aplicación. Aquí trabajamos en la parte del desarrollo web que trabaja "detrás de escena", encargándose de la lógica, bases de datos, servidores y todo lo que hace funcionar una app aunque no lo veas.

## Integrantes del proyecto

- **Sebastián Peralta** - Desarrollador de Backend. Encargado en el servidores de bases de datos para recuperar o modificar datos relevantes.
- **Demián Ferreyra** - Desarrollador de Flontend. Encargado de que los usuarios puedan interactuar con la Aplicación(Interfaz Gráfica).
- **Brisa Nieva** - Encargada de Documentación y Testing.

## Tecnologías Usada En El Proyecto

- JDK 17
- IntelliJ IDEA
- Postman
- Maven
- Docker
- Git/GitHub
